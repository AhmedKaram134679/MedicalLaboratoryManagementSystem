# نظام إدارة معمل التحاليل الطبية (Medical Laboratory Management System)

## 1️⃣ نظرة عامة على النظام

**اسم النظام:** Medical Laboratory Management System **المنصة:** Flutter Desktop
(Windows Only) **نوع التطبيق:** تطبيق داخلي (Offline First) يعمل في الخلفية على
الويندوز.

**الهدف من النظام:**

- إدارة كاملة واحترافية لمعمل التحاليل الطبية.
- تقليل الأخطاء اليدوية وتسريع عمليات التسجيل.
- توحيد شكل التقارير والإيصالات.
- متابعة مالية دقيقة وإدارة المخزون والديون.
- قابلية التوسع مستقبلاً.

## 2️⃣ المستخدمون والأدوار (Users & Roles)

### Admin (مدير المعمل)

- **الصلاحيات:** كاملة (Full Access).
- **المهام:**
  - إضافة / تعديل / حذف كل شيء.
  - اعتماد النتائج والتراجع عن الاعتماد.
  - إدارة المستخدمين والصلاحيات.
  - إعدادات النظام.
  - النسخ الاحتياطي والاسترجاع.

### User (مستخدم عادي / فني)

- **المهام:**
  - تسجيل المرضى.
  - إدخال النتائج.
  - حفظ النتائج (Draft / Completed / Approved).
  - اعتماد النتائج (لا يمكنه إلغاء الاعتماد).

## 3️⃣ قاعدة البيانات (Database)

- **النوع:** SQLite (الأساسية).
- **التكامل مع Excel:**
  - تصدير التقارير.
  - استيراد بيانات (مع خيارات المراجعة والمعاينة).
  - توليد ملفات Excel تلقائيًا.
- **الخصائص:**
  - Offline 100%.
  - Sync اختياري مع Google Drive.
  - نسخ احتياطي (Backup) تلقائي ويدوي.
  - Audit Log لكل عملية.

## 4️⃣ نظام تسجيل الدخول (Login System)

- **الواجهة:** Desktop احترافية.
- **الحقول:** Username, Password.
- **الزر:** Login.
- **الحساب الافتراضي:** `admin` / `admin`.
- **الخصائص:**
  - بدون منطق Backend في الواجهة (Local Auth).
  - دعم "نسيت كلمة المرور" (إرسال طلب للمدير).

## 5️⃣ الواجهة العامة (General Layout)

### لوحة التنقل (Navigation Panel - ثابتة)

- Dashboard (لوحة التحكم).
- تسجيل المرضى (Patient Registration).
- إدخال النتائج (Results Entry).
- المخزون (Inventory).
- التقارير (Reports).
- الإعدادات (Settings).

### شريط الإشعارات (Notification Bar - أسفل الشاشة)

- يظهر عند وجود أحداث مهمة (مثل شريط الأخبار):
  - قرب نفاذ مادة.
  - تحاليل غير مكتملة.
  - ديون قديمة.

## 6️⃣ لوحة التحكم (Dashboard)

### Widgets رئيسية

- عدد المرضى اليوم.
- عدد التحاليل الجارية.
- إجمالي المدفوع والمتبقي (اليوم).
- **تحذيرات:** مخزون منخفض، ديون، تحاليل غير مكتملة.

### الرسومات البيانية (Charts)

- Top 10 Tests (أكثر 10 تحاليل طلباً).
- الإيرادات الشهرية ونمو الإيرادات.
- نسبة النتائج الطبيعية vs غير الطبيعية.
- **المظهر:** دعم Dark Mode / Light Mode وتحديث مباشر للبيانات.

## 7️⃣ تسجيل بيانات المرضى (Patient Registration)

### البيانات الأساسية

- **Patient ID:** رقم تلقائي (Auto-increment) يعاد ضبطه يومياً (يبدأ من 1).
- اسم المريض، السن (يدوي)، النوع، رقم الهاتف (مع خيار Is WhatsApp).
- ملاحظات، تاريخ الزيارة (قابل للتعديل)، الطبيب المحول (قائمة منسدلة + إضافة
  جديد).

### التحاليل المطلوبة (Tests Selection)

- 3 قوائم منسدلة افتراضياً.
- زر **➕ Add Test** لإضافة تحليل جديد (قائمة + سعر).
- السعر يظهر تلقائياً (غير قابل للتعديل).
- **الخصم:** عام على الفاتورة وليس لكل تحليل.

### الحسابات المالية

- إجمالي المطلوب (Auto).
- الخصم (يدوي).
- الصافي (Net).
- المدفوع (يدوي).
- المتبقي (Auto).

### الأزرار والوظائف

- حفظ، تعديل، حذف، جديد.
- طباعة إيصال (مع معاينة).
- إرسال WhatsApp.

## 8️⃣ تصميم الإيصال (Receipt)

- **المحتوى:** شعار المعمل، البيانات، جدول التحاليل، الحسابات المالية.
- **الإضافات:** توقيع (نص)، QR Code (لتقييم الرضا أو المراجعة).
- **التنسيق:** A4، PDF، تصميم جاهز (صورة خلفية)، دعم عربي/إنجليزي (بدون انعكاس).

## 9️⃣ إدخال النتائج (Results Entry)

### التصميم

- **Navigation Panel:** للتنقل العام.
- **Patient List Panel:** قائمة مرضى اليوم (بحث سريع).
- **Results Area (Tab System):**
  - تابات بعدد التحاليل المطلوبة للمريض.
  - كل تحليل له تصميم خاص (Custom Template) يعتمد على صور جاهزة.
  - جدول أفقي لبيانات المريض، وعمودي للقيم.

### القيم والنورمال (Normal Ranges)

- تختلف القيم الطبيعية حسب السن والنوع (Logic Comparison).
- **التلوين التلقائي:**
  - طبيعي: أسود.
  - أقل/أعلى من الطبيعي: أصفر/أحمر.
  - Positive: **Bold**.
  - Negative: عادي.
- **أنواع القيم:** رقمية أو نصية (Positive/Negative).
- **حالات الحفظ:**
  - **Draft:** مسودة قابلة للتعديل.
  - **Completed:** مكتملة للمراجعة.
  - **Approved:** معتمدة وجاهزة للطباعة (لا يمكن التعديل بعدها إلا من الأدمن).
- **التنقل:** تحذير عند الانتقال دون حفظ.

### الطباعة

- زر Print (Ctrl+P).
- حفظ PDF وتوجيه مباشر للطابعة.

## 🔟 المخزون (Inventory)

- **البيانات:** اسم المادة، النوع، الكمية، الحد الأدنى، الصلاحية.
- **التنبيهات (Color Coded):**
  - 🟢 آمن.
  - 🟡 قرب النفاذ.
  - 🔴 نفذت / منتهية الصلاحية.
- **الربط التلقائي:** خصم الكميات عند تسجيل التحاليل.

## 1️⃣1️⃣ التقارير (Reports)

- يومي، شهري، سنوي.
- تصدير Excel / PDF.
- رسوم بيانية للأرباح والخسائر والتحاليل الأكثر طلباً.

## 1️⃣2️⃣ الإعدادات (Settings)

- معلومات المعمل.
- المستخدمون والصلاحيات.
- الأطباء والتحاليل (تعديل الأسعار والقيم الطبيعية).
- القوالب وتخصيص الطباعة.
- اللغة والنسخ الاحتياطي (Auto/Manual).

## 1️⃣3️⃣ النسخ الاحتياطي (Backup)

- يدوي وتلقائي (يومي/أسبوعي/شهري).
- تخزين محلي (Local) + Google Drive (اختياري).
- تشفير البيانات قبل الرفع.
- واجهة استرجاع (Restore) بسيطة.

## 1️⃣4️⃣ السجلات والمراقبة (Logs & Audit)

- تسجيل كامل للعمليات (إضافة، تعديل، حذف، استيراد، تصدير).
- يشمل: اسم المستخدم، الوقت، نوع العملية.
